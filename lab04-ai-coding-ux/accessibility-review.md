## Review จุดที่ร่าง AI พลาดและการแก้ในร่างนี้
การแก้ต่อไปนี้ทำโดย Codex ตามคำขอผู้ใช้ ไม่ใช่การแก้ของนักศึกษา: หากส่งงาน ผู้เรียนต้องตรวจ mockup ด้วยตัวเองและบันทึกการแก้ของตน.

1. หน้า Login: ร่างแรกใช้ error รวม “กรุณากรอกชื่อผู้ใช้และรหัสผ่าน” จึงไม่บอกว่าช่องใดต้องแก้. แก้เป็นข้อความใต้ช่องชื่อผู้ใช้และช่องรหัสผ่านแยกกัน พร้อมคำแนะนำ; ทั้งสองข้อความใช้ ! และข้อความ ไม่พึ่งสีอย่างเดียว.
2. หน้า Add Product: ร่างแรกวาง error ราคาทั่วไปไว้นอกลำดับช่อง และอาจถูกเข้าใจว่าใช้ร่วมกับชนิดสินค้าทุกแบบ. ย้ายคำแนะนำไว้ชิดช่องราคา และแยกส่วนจำนวน/threshold ของสินค้าจับต้องได้ออกจากช่องไฟล์ดิจิทัลที่ไม่ตัด stock.

ตรวจ Tab order จาก layout ได้เพียงการคาดการณ์ ยังต้องตรวจด้วย keyboard ใน mockup/UI ที่โต้ตอบได้จริง.
